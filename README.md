# 财报表格中的比较范围

同一张表里会同时出现年度、分项和合计。回答“哪一年收入最高”之前，程序需要先选定比较范围。本实验用 Python 枚举候选行列、执行数值比较，并记录答案来自哪些单元格。

## 运行一个例子

在本目录运行 `python example.py`，观察合成表格的答案和单元格坐标。`compare.py` 只依赖 Python 标准库。

## 实验记录

历史评测使用 TAT-QA 开发集的 171 道表格来源、单一片段答案问题，其中 57 道带有比较标记，114 道作为对照。各方法共享回退预测，代码示例只演示规则执行器。

| 方法 | 57 道比较题 | 全部 171 题 |
| --- | ---: | ---: |
| 直接查找与模型回退 | 15 | 101 |
| 扁平范围执行器与回退 | 42 | 128 |
| 分层范围执行器与回退 | 45 | 131 |
| 增加范围判别步骤与回退 | 45 | 131 |

表中数值为归一化答案完全匹配的题数。分层执行器在比较题上比扁平执行器多答对 3 题。再加入范围判别步骤，两组自然题上的总分均持平。在另行构造的 16 道改写问题上，两者分别答对 12 题和 11 题。

[实验协议](protocol.json)记录了选题条件、输入和评分方法。[自然题汇总](summary.json)和[改写题汇总](challenge_summary.json)保留了分组结果。方法代码的 SHA-256 可与[冻结记录](freeze.json)核对。仓库提供方法演示和历史汇总，完整重算还需原始数据与回退预测。
